## About

**HyperVision AI** is an advanced AI-powered spatial learning platform built by **Nikhil Vashishtha**. It transforms traditional classroom education into an immersive, interactive 3D holographic experience — combining real-time AI tutoring, virtual laboratories, gesture controls, voice commands, live transcription, and collaborative multiplayer learning into one unified browser-based platform.

> *"The world's most advanced AI classroom — where you don't just read about atoms, you hold them in your hands."*

## Features

- 🌌 **3D Holographic Viewer** — 50+ interactive science, engineering & history models
- 🤖 **AI Neural Tutor** — Powered by Google Gemini with multi-depth explanations
- 🧪 **Virtual Laboratory** — Full physics-simulated experiments, no real lab needed
- ✋ **Gesture Control** — MediaPipe hand tracking for hands-free interaction
- 🎙️ **Voice Controller** — Full voice command support
- 📖 **NCERT Book Reader** — Direct integration with official textbooks
- 🌐 **Multiplayer Classroom** — Real-time collaborative sessions via Socket.IO
- 🧊 **AI 3D Generation** — Text or image to 3D model using Meshy AI
- 📊 **Progress Dashboard** — Student analytics and achievement tracking
- 👩‍🏫 **Teacher Suite** — Attendance, transcription, lesson creator, task manager

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

React 19 · TypeScript · Vite · Three.js · Google Gemini API · MediaPipe · Firebase · Socket.IO · TailwindCSS · Framer Motion · WebXR
